## 仿真世界

> 通过生成式模拟发现未知的不安全事件 [TeraSim](https://github.com/mcity/)



### 一、服务器环境准备

最低配置要求：

- CPU：4 核
- RAM：16GB（建议 32GB）
- 磁盘：50GB+
- OS：Ubuntu 20.04 / 22.04

安装 Docker 和 Docker Compose：

```shell
*# 安装 Docker*

curl -fsSL https://get.docker.com | sh

sudo usermod -aG docker $USER

newgrp docker

*# 验证安装*

docker --version

docker compose version
```



------

### 二、拉取项目并构建镜像

```shell
git clone https://github.com/mcity/TeraSim.git

cd TeraSim

*# 配置 API 密钥（运行 TeraSim-World 必须）*

cp .env.example .env   *# 如果有示例文件*

nano .env

`.env` 文件中填入：

OPENAI_API_KEY=你的OpenAI密钥

GOOGLE_MAPS_API_KEY=你的GoogleMaps密钥
```



构建并启动（加速构建）：

*# 启用 BuildKit 加速构建*

DOCKER_BUILDKIT=1 docker compose up -d --build

> 首次构建约需 10-20 分钟，镜像约 2-3 GB。

### 三、核心使用方式

#### 进入容器

docker compose exec terasim bash

#### 运行不同任务

| 任务          | 命令                                                         |
| :------------ | :----------------------------------------------------------- |
| 标准仿真      | `docker compose exec terasim python run_experiments.py`      |
| 调试模式      | `docker compose exec terasim python run_experiments_debug.py` |
| 启动 API 服务 | `docker compose exec terasim python run_service.py`          |
| 运行示例      | `docker compose exec terasim python examples/scripts/example.py` |
| 运行测试      | `docker compose exec terasim pytest`                         |

### 四、TeraSim-World 完整工作流

Step 1：生成指定地点的仿真场景

*# 以密歇根州安娜堡某路口为例（经纬度可替换为任意地点）*

docker compose exec terasim python scripts/generate_experiments.py \

​    --lat 42.31708742783425 \

​    --lon -83.70771003426997 \

​    --bbox 500 \

​    --output generated_experiments \

​    --name ann_arbor_roundabout

参数说明：

- `--lat / --lon`：场景中心的经纬度
- `--bbox`：仿真区域边长（米），默认 500
- `--output`：输出目录
- `--name`：场景名称

Step 2：调试模式运行仿真

docker compose exec terasim python scripts/run_experiments_debug.py \

​    --config path/to/your/config.yaml

Step 3：转换为 Cosmos-Drive 格式（用于视频生成）

docker compose exec terasim python scripts/convert_terasim_to_cosmos.py \

​    --path_to_output /path/to/output \

​    --path_to_fcd /path/to/fcd_all.xml \

​    --path_to_map /path/to/map.net.xml \

​    --vehicle_id vehicle_001 \

​    --time_start 460.0 \

​    --time_end 464.0 \

​    --streetview_retrieval

### 五、服务器端口与数据持久化

端口映射：

| 端口   | 用途                 |
| :----- | :------------------- |
| `8000` | TeraSim FastAPI 接口 |
| `6379` | Redis 数据库         |

挂载目录（数据自动持久化到宿主机）：

./outputs  ←→  容器内 /app/TeraSim/outputs  （仿真结果）

./logs     ←→  容器内 /app/TeraSim/logs     （日志）

### 六、调整服务器资源限制

编辑 `docker-compose.yml`，根据服务器实际配置调整：

deploy:

  resources:

​    limits:

​      cpus: '8'      *# 改为你的 CPU 核数*

​      memory: 16G    *# 改为你的内存上限*

​    reservations:

​      cpus: '4'

​      memory: 8G

### 七、常用运维命令

*# 查看容器运行状态*

docker compose ps

*# 查看实时日志*

docker compose logs -f terasim

*# 查看最近 50 行日志*

docker compose logs --tail=50 terasim

*# 重启容器*

docker compose restart terasim

*# 停止并移除容器*

docker compose down

*# 重新构建（代码有变更时）*

docker compose up -d --build

*# 清理缓存重新构建*

docker compose build --no-cache

### 八、常见问题排查

Redis 连接问题：

docker compose exec terasim redis-cli ping

*# 正常返回 PONG*

*# 手动启动 Redis*

docker compose exec terasim redis-server --daemonize yes

SUMO_HOME 未设置：

docker compose exec terasim echo $SUMO_HOME

*# 应返回 /root/.terasim/deps/sumo*

docker compose exec terasim sumo --version

挂载目录权限问题：

chmod -R 777 outputs logs

*# 或*

sudo chown -R $USER:$USER outputs logs

Python 模块导入失败：

docker compose exec terasim python -c "import terasim; print(terasim.__version__)"

*# 重新安装包*

docker compose exec terasim pip install -e packages/terasim

### 九、如果需要 GPU 支持（TeraSim-Cosmos）

服务器需安装 NVIDIA Container Toolkit：

sudo apt-get install -y nvidia-container-toolkit

sudo nvidia-ctk runtime configure --runtime=docker

sudo systemctl restart docker

*# 验证*

docker run --rm --gpus all nvidia/cuda:11.8.0-base-ubuntu22.04 nvidia-smi

*# 启动 GPU 版容器*

cd packages/terasim-cosmos

docker compose -f docker-compose.gpu.yml up -d --build

docker compose -f docker-compose.gpu.yml exec terasim-cosmos bash
