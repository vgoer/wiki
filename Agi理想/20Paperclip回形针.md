## Paperclip回形针

> 用于管理工作场所的代理人。[github](https://github.com/paperclipai/paperclip)
>
> Paperclip 是一个基于 Node.js 服务器和 React 用户界面的框架，用于协调 AI 代理团队来运营业务。您可以自带代理，分配目标，并通过一个控制面板跟踪工作进度和成本。您可以为每个代理选择模型和工具，同时将团队的任务、技能、权限和历史记录集中在一个地方。



### 1. 安装

> 安装 [doc](https://docs.paperclip.ing/)

* 极速安装

```shell
npm install -g corepack
corepack enable
corepack prepare pnpm@latest --activate


#  运行
npx paperclipai onboard --yes

# 启动
npx paperclipai install
paperclipai service install
```

* 源码部署

```shell
git clone https://github.com/paperclipai/paperclip.git
cd paperclip
pnpm install
pnpm dev
```
