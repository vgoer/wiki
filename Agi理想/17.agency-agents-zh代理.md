### 4. 进阶使用

a. 串行接力

```shell
我想做一个口语的app
第 1 步：激活 UX 研究员
→ 输出用户调研报告

第 2 步：激活产品经理（输入调研报告）
→ 输出产品需求文档

第 3 步：激活后端架构师（输入需求文档）
→ 输出 API 设计和数据库 Schema

第 4 步：激活前端开发者（输入 API 设计）
→ 输出前端代码
```



b. 并行工作

```shell
我想做一个帮送的app。
并行激活：
- 后端架构师：设计 API
- UI 设计师：设计界面原型
- 安全工程师：制定安全规范

汇总后激活前端开发者，综合所有输出开始开发。
```



c. 审查验证

```shell
1. 激活前端开发者，写登录模块代码
2. 激活代码审查员，审查登录模块代码
3. 激活安全工程师，做安全审计
4. 前端开发者根据审查意见修改
```







### 5. 多角色

> ao

```shell
npm install -g agency-orchestrator

# 初始化
ao init

# 些工作流
ao compose "帮我写一篇关于 AI Agent 的深度分析文章" --run --provider claude-code

ao compose "帮我写一个帮送的app，需要ui，产品，前后端，测试，运维，移动端，代码审查员都参见到开发者" --run --provider claude-code

# 查看可以使用的角色
ao roles 

# 查看计划
ao plan .\workflows\帮我写一个帮送的app需要ui产品前后端测试运维移动端代码审查员都参见到开发者.yaml
 
# 执行
ao run .\workflows\帮我写一个帮送的app需要ui产品前后端测试运维移动端代码审查员都参见到开发者.yaml

# 执行
```
