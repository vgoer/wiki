## Hermes Agent

> **Hermes Agent**（由 Nous Research 开发）是一套强调“自主学习、沉淀 Skill、跨会话记忆”的个人 AI 智能体 Runtime。它不仅能执行任务，还能反思优化自己的工作流。
>
> [github](https://github.com/NousResearch/hermes-agent) [doc](https://hermes-agent.nousresearch.com/docs)





### 1. 安装

```shell
# linux/ mac
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

# win
iex (irm https://hermes-agent.nousresearch.com/install.ps1)

# 启动
source ~/.bashrc   # or: source ~/.zshrc
hermes             # Start chatting!
```



### 2. 配置

```shell
# 交互配置
hermes gateway setup
```
