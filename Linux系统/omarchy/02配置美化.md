## 配置美化

> 配置美化





### 1. 插件

> omacale  [github](https://github.com/AyushKr2003/omacale)

```shell
omarchy plugin add https://github.com/AyushKr2003/omacale.git --enable
```



>  可选设置

- **快捷键**：设置 › 快捷键，或粘贴[`keybinds.lua`](https://github.com/AyushKr2003/omacale/blob/main/keybinds.lua)到`~/.config/hypr/bindings.lua`

- **窗口样式**：添加到`~/.config/hypr/looknfeel.lua`：

  ```
  pcall(dofile, os.getenv("HOME") .. "/.config/omarchy/plugins/omacale.bar/omacale.lua")
  ```

- **Toast 和 OSD**：安装时询问，默认开启（`--osd`/ `--no-osd`）

- **锁屏**：选择加入（`--lock-screen`）

- **移除**：（`./uninstall.sh`非`omarchy plugin remove`）
